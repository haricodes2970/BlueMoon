# Phase Documents

One document per milestone, updated whenever that milestone's work
changes (not just at completion). These are more granular than
[Engineering-Journal.md](../engineering/Engineering-Journal.md)'s
one-entry-per-milestone summaries — a phase document is the full
record (files touched, problems found/solved, quality gate results,
lessons learned) for that specific milestone.
